**Goal:** Create and verify the immutable raw page layer for the 1220-page Tome 1 PDF without repairs, mapping, structure, semantic extraction, chunking, embeddings, database writes, or shared-code changes.

**Interfaces:**
- `extract_page(document: Document, page_index: int) -> dict` — extract one page and return a raw page record.
- `extract_raw(source_path: Path, output_dir: Path) -> dict` — extract every page independently and return the run summary.
- `build_page_record(page_index: int, raw_record: dict, raw_file: str) -> dict` — produce the page summary.

Raw record contract:

```text
page_id
source_page_index
source_page_display
raw_text
raw_text_sha256
coordinates_sha256
block_sequence_sha256
blocks
parser
extraction_status
```

Extraction rules:

- Use `page.get_text("text", sort=False)`.
- Use `page.get_text("blocks", sort=False)`.
- Preserve the returned block order.
- Store block order, text, text hash, and bounding box.
- Do not normalize, repair, translate, or deduplicate text.
- Do not call `pages.map.json` or infer printed page numbers.
- One page failure produces a page record with `extraction_state: failed`, `processing_state: not_applicable`, `extraction_checkpoint_status: terminal`, and a failure detail.
- A successful page has `extraction_state: extracted`, `processing_state: pending`, and `extraction_checkpoint_status: terminal`.
- Raw files are written once with exclusive creation semantics where supported.
- An existing raw file is never overwritten.

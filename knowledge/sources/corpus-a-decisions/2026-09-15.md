# Decisions — bornes non cliniques du poste de travail

Provenance : docs/00-DECISIONS.md (revue R1). Aucune recommandation clinique.

## Localite des donnees

Toute donnee identifiante patient reste sur le PC du cabinet. Aucune sortie vers un cloud, jamais, sous aucun pretexte.

## Passerelle unique

Tout appel vers une API externe passe par une fonction serveur unique qui retire les identifiants et les remplace par des jetons. Re-hydratation locale au retour. Aucun appel direct depuis le client.

## Cles serveur uniquement

Aucune cle dans le code client, dans le depot, dans le .env versionne, ni dans un message de chat. Variables d'environnement serveur uniquement.

## Ecritures confirmees

Aucune action d'ecriture sans confirmation explicite affichee a l'ecran. Chaque action executee est journalisee.

## Notes immuables

Signature puis gel. Correction par amendement visible, jamais par ecrasement.

## Audit des acces

Toute lecture et ecriture de donnee clinique est tracee : qui, quoi, quand, depuis ou.

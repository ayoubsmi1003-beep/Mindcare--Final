# Alexa · Fiche pour la praticienne

Vous pouvez utiliser les fonctions déjà disponibles pour consulter un dossier, l’agenda ou les références médicales du cabinet. Pour une action sensible, Alexa prépare une proposition et vous demande de la confirmer avant l’exécution.

Si une demande concerne un dossier, sélectionnez le patient ou précisez son identité en cas d’ambiguïté. Pour une demande qui combine le dossier et une question médicale, vérifiez séparément les éléments du dossier et les extraits des références cités par Alexa. Quand un volet manque, demandez une précision sur ce volet.

Le travail Laya se déroule sur des questions synthétiques. Les résultats de laboratoire ne changent pas ce que vous pouvez utiliser dans la version installée.
